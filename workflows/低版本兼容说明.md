# 低版本 ComfyUI 前端兼容性

**结论：面板从 ComfyUI 前端 1.12.8 起可用。** 更早的版本（内置前端的
1.3.x ~ 1.11.x）不在 PyPI 上，我无法取得，所以**没有实测过**，但从 API 契约看
面板依赖的都是 LiteGraph 时代的接口，理论上也能用。

---

## 我依赖了哪些前端 API

| API | 用途 | 老版本有吗 |
|---|---|---|
| `app.registerExtension({ name, beforeRegisterNodeDef })` | 注册扩展 | 有（1.12.8 起） |
| `node.addWidget("button", name, val, cb)` | 加按钮 | LiteGraph 原生，一直有 |
| `node.addDOMWidget(name, type, el, opts)` | 节点上的预览框 | 有；**老前端忽略第 4 个参数** |
| `node.addDOMWidget` 缺 `options` 字段 | —— | **补了防线**（见下） |
| `node.size` / `node.setSize` / `setDirtyCanvas` | 尺寸与重绘 | 一直有 |
| `graph.links[id]` | 找下游采样器 | 有；老对象用 `target`，新用 `target_id`（两种都兼容） |
| `graph.getNodeById` | 找下游节点 | 有；**缺失时退回 `graph._nodes_by_id`** |
| `widget.options.control_after_generate` | 种子随机/递增 | 有 |
| `IntersectionObserver` | 角色卡懒加载 | 浏览器 API；没有时**自动换成「加载更多」按钮** |

---

## 为老前端补的三处防线

### 1. `addDOMWidget` 的第 4 个参数会被忽略 → 退回画布绘制

老前端的签名是 `addDOMWidget(name, type, element)`，**没有第 4 个 config**。
所以 `getHeight / getMinHeight / getMaxHeight` 都不会被读到。

现在如果 `addDOMWidget` 不存在或抛异常，节点预览会**自动退回画布绘制模式**
（用 `onDrawForeground` 画几行文字），而不是抛异常把 `setupBuilder` 打断 ——
后者会导致「连打开面板的按钮都没有」。

### 2. `widget.options` 可能不存在 → 全部补 `|| {}`

老前端（1.12.x）的 `addWidget` 不一定带 `options` 字段。
原来直接写 `refresh.options.serialize = false` 会抛 `TypeError`，
**整个 setupBuilder 中断**。现在 5 处访问全部有 `x.options = x.options || {}` 前置。

### 3. `graph.links[id]` 的字段名 → `target_id` / `target` 都支持

老前端的 link 对象用 `target`，新的是 `target_id`。种子推送那段两种都认。

## 怎么自己验证

### 离线（不用开 ComfyUI）

加了第三个测试模式 `--oldfe`，模拟老前端的 DOM widget 契约
（`addDOMWidget` 只收 3 个参数、按钮 widget 没有 `options`、link 用 `target`、
`graph.getNodeById` 返回 null）：

```bash
node tools/animansfw_panel_smoke.mjs            # 现代前端
node tools/animansfw_panel_smoke.mjs --legacy   # 剥掉 addDOMWidget 等
node tools/animansfw_panel_smoke.mjs --oldfe    # 老前端契约（1.12.x）
```

三种模式都必须全绿。

### 真机验证（会动你的环境，谨慎）

```bash
# 1. 记下当前版本
pip show comfyui-frontend-package

# 2. 降级到老前端
D:\ComfyUI-aki-v2\python\python.exe -m pip install "comfyui-frontend-package==1.12.8"

# 3. 重启 ComfyUI，浏览器 Ctrl+F5
# 4. 验证面板能打开、能套用剧情

# 5. 恢复正常版本
D:\ComfyUI-aki-v2\python\python.exe -m pip install -r requirements.txt
```

> ⚠️ 降级前建议先备份工作流。前端版本回退后，工作流里新版节点（例如
> `ImageGridComposite2x2` 之类）可能显示不出来 —— 那是前端不认识节点类型，
> 不是面板的问题。

---

## 如果真的是「打不开面板」，按这个顺序排查

1. **Ctrl+F5 硬刷新**（最常见的其实是浏览器缓存）
2. F12 看控制台有没有 `[AnimaNSFW]` 开头的报错
3. 看服务端日志里本包有没有 `IMPORT FAILED`
4. `curl http://127.0.0.1:8188/anima_nsfw/tags` 有没有返回 JSON
   （拿不到就是后端/端口问题，跟前端版本无关）
5. `curl http://127.0.0.1:8188/extensions/ComfyUI-Anima-NSFW-Panel/anima_nsfw_panel.js`
   有没有返回 JS（拿不到就是静态资源路径问题）
6. 以上都正常 → 才可能是前端版本问题，试试上面那个降级验证
