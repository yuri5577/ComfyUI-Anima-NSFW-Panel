# 面板窄视口布局（左侧栏显示不完整）

## 用户反馈

> 左边的选项显示不完整

截图里能看到侧栏的「全部标签」「露骨 / 强度」「存为触发词」都被切掉了。

## 真正的根因（查了很久，值得记下来）

**不是"侧栏太窄"，而是面板子树里有元素横向溢出。**

```
panel.clientWidth = 1178px
panel.scrollWidth = 1373px      ← 溢出 195px！
```

面板子树里**唯一**溢出的元素是 **header**：

```
text: "Anima NSFW 面板 点选标签 → 自动互斥 / 排序 …"
display: flex,  flexWrap: nowrap     ← 就是这里
```

头部的 10 个按钮 + 搜索框排成一行，需要 1373px，而 `flexWrap` 默认是 `nowrap`，
**不肯折行**。于是：

1. 面板子树被撑到 1373px（面板本身只有 1178px）
2. 溢出的内容在面板内被**居中**，整体向左推 **91px**
3. 面板是 `overflow: hidden`（圆角需要），于是**左边 91px 被直接裁掉**
4. 侧栏就在左边 —— 被切掉的正是它

## 定位过程里的关键线索

偏移量 **恒定 91px**，与视口宽度完全无关（1600px 和 320px 下都是 91px）。
一开始我以为是"侧栏太窄"，试过给侧栏设最小宽度、按可用宽度收缩、
让面板横向滚动 —— 都没解决，因为方向错了。

最终定位靠的是这两个数字对不上：

```
panel.offsetLeft        = 199     ← 布局说：面板在 x=199
panel.getBoundingClientRect().left = 108   ← 渲染说：内容在 x=108
差值恒定 91px
```

`offsetLeft` 与 `rect` 差一个定值，说明有东西被**裁剪/居中**了，而不是简单的宽度不足。
顺着 `scrollWidth - clientWidth` 找到唯一溢出者，就是 header。

> 中途还排除过两个怀疑对象（都不是）：
> * overlay 的 `backdrop-filter: blur(2px)` —— 去掉后偏移不变
> * `box-shadow` / `border-radius` —— 去掉后偏移不变

## 修法

### 1. header 允许折行（这是根本修复）

```js
const header = el("div", {
    display: "flex", alignItems: "center", gap: "10px",
    flexWrap: "wrap", minWidth: "0", maxWidth: "100%",   // ← 关键
    ...
});
```

折行后 header 最多占满面板宽度，不再撑宽子树。
实测 `panelScrollW` 从 1373 → **1178 = clientWidth**，溢出 0。

### 2. 窄面板时侧栏改为顶部横向条

光修 header 还不够：面板窄到 400px 时，"左侧 186px 竖栏 + 网格" 再怎么也挤不下。
所以面板宽度 < 640px 时：

* 侧栏 `flexDirection` 从 row 改成 **column**（横过来占满整个面板宽度）
* 分类按钮换成**多列网格**（`repeat(auto-fill, minmax(104px, 1fr))`）
* 网格在下面拿满宽度

```js
const NARROW_BREAK = 640;

function applyResponsiveLayout() {
    const w = box.getBoundingClientRect().width || 1180;
    const narrow = w < NARROW_BREAK;
    if (narrow) {
        body.style.flexDirection = "column";
        side.style.width = "100%";
        side.style.maxHeight = "44vh";
        side.style.borderBottom = `1px solid ${THEME.line}`;
        // 分类列表排成多列，别拉成一长条
        catList.style.display = "grid";
        catList.style.gridTemplateColumns = "repeat(auto-fill, minmax(104px, 1fr))";
    } else {
        body.style.flexDirection = "row";
        side.style.width = "186px";
        ...
    }
}
```

用 `ResizeObserver` 监听面板宽度（回退到 `window.resize`），关闭面板时断开。

> ⚠️ 首次调用 `applyResponsiveLayout()` **必须放在面板构建末尾** ——
> 它引用 `catList` / `workList`，那两个是后面才创建的 `const`，
> 提前访问会 TDZ 报错（`Cannot access before initialization`）。

|---|---|---|---|---|---|---|

| 1100 | 1056 | 0 | 左右 | 186 | 0 | 0 |

修复前：1600px 下就已经偏移 91px、切掉侧栏左侧。

## 验证

```bash
node tools/animansfw_browser_sidebar.mjs
```

测试断言（都基于"内容必须在面板边界内"这个可证伪的条件）：

1. 所有宽度下**面板子树无横向溢出**（`scrollWidth <= clientWidth + 1`）
2. 所有宽度下**没有控件超出面板左右边界**
3. 所有宽度下**分类名都没被省略号裁掉**
4. 所有宽度下**侧栏左边界落在面板内**
5. 窄面板（420px）侧栏在网格**上方**，网格仍有可读宽度
6. 宽面板（1600px）侧栏回到左侧竖列、面板仍是 1180px（观感不变）

## 顺带修的

* `addCat()` 的分类名 `span` 加 `minWidth: 0` + 省略号 —— flex 子项默认
  `min-width: auto`（等于内容宽度），长标签会把右边的数字顶出去
* `window.addEventListener("resize", ...)` 加 `typeof` 判断 ——
  离线冒烟测试用的 DOM 桩没有 `addEventListener`，直接调用会把整个面板构建
  打断（表现是"点击后面板浮层没出现"）。这个是我自己引入的回归，已修
